# SFF Sandbox
Welcome to **SFF Sandbox** - a 2D sandbox game that combines the best elements of **Minecraft** and **Terraria**!

## Features
- Placing/destroying blocks.

## Build
### CMake (MinGW is unsupported, clang is recommended)
``` bash
cmake -B build
cmake --build build
```
